# DotEnvy icon

Primary asset: `icon.png`. Used by the extension package and activity-bar container.
DE abbreviates DotEnvy; the key represents environment secrets. The square mark
uses the existing dark teal, mint and amber visual direction, with transparency
outside the rounded tile. Generated with the built-in `image_gen` tool, then
copied into this repository without altering the generated image.

## Generation prompt

Use case: logo-brand. Asset type: final square VS Code extension icon for DotEnvy. Create ONE clean, polished app icon, not a presentation or mockup. Main mark: exactly the two uppercase letters "DE" (D then E), large, unmistakably readable bold geometric sans-serif lettering. Include ONE simple, clearly recognizable horizontal key immediately below the letters, with a circular hollow bow on the left, a stout shaft, and two short square teeth at the right. Integrate the key and monogram into a balanced compact composition; the letters remain the primary focus. Use the existing DotEnvy visual direction of dark teal, light mint and warm amber: an opaque dark teal rounded-square tile, pale ivory D, mint E, amber-gold key. Genuine transparency outside the rounded tile. Flat graphic design with crisp smooth vector-like edges, generous stroke thickness and ample safe padding, strong silhouette and high contrast that remains readable at 32px. Center the tile in a square canvas and have it fill almost all the image. The DE letters and key together fill most of the tile without touching its edges. No full word DotEnvy, no additional text, no gear, dots, shield, padlock, coding brackets, badge, texture, bevel, 3D, glow, shadow, gradient, watermark, border, or surrounding illustration.
